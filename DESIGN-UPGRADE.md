# Birthday Website — Visual Design Upgrade

The supplied `Designs.zip` artwork has been integrated into the existing birthday website page-by-page from **00 to 07**.

## Page mapping

- **00** — secret entry: Cinnamoroll flying, birthday cake, Cinnamoroll eating cake
- **01** — birthday opening: yarn ball and Cinnamoroll peek pose
- **02** — memory bridge: grass textures, second grass layer, Cinnamoroll star pose
- **03** — pink console: Cinnamoroll love pose and Roblox character
- **04** — letters: Cinnamoroll, Hello Kitty, Keroppi, Kuromi and Pompompurin holding mail
- **05** — photobooth: loving couple, Roblox group, photobooth illustration
- **06** — television room: tender Cinnamoroll and Sanrio Friends pose
- **07** — final message: cat with birthday cake

## Visual effects added

- Layered decorative artwork behind the primary UI and text
- Soft halo lighting around artwork
- Floating / breathing motion for illustrations
- Pointer parallax on desktop
- Animated light sheen across the artwork
- Small ambient sparkles per scene
- Drop shadows and depth for scrapbook / handmade-card feeling
- Paper-like texture and subtle visual grain remain part of the scenes
- Readability treatment for large headings and paragraph copy
- Responsive positioning so decorations stay away from important controls
- Reduced-motion handling for accessibility

## Main files changed

- `index.html`
- `birthday.html`
- `src/main.ts`
- `src/design-effects.ts` (new)
- `src/styles/global.css`
- `public/designs/*` (new integrated artwork assets)

The original supplied artwork was converted into web-friendly transparent versions where the source PNG used a light background, so the characters and objects can blend into the existing visual scenes without rectangular white boxes.
